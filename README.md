# ProtectUSB - Ֆայլերի և USB կրիչների պաշտպանության համակարգ

## Նախագծի մասին
Այս նախագիծը C++ կոնսոլային ծրագիր է, որը նախատեսված է տեղային ֆայլերի և USB կրիչների պարունակության անվտանգ գաղտնագրման համար: 

## Ինչ է արվել (Հիմնական փոփոխություններ)
Լաբորատոր աշխատանքի շրջանակներում կատարվել են հետևյալ բարելավումները.
1. **Ալգորիթմի փոխարինում:** Պարզ և խոցելի XOR գաղտնագրումը փոխարինվել է արդյունաբերական ստանդարտ հանդիսացող **AES-256** ալգորիթմով՝ օգտագործելով ներկառուցված Windows CryptoAPI (CNG):
2. **Բանալու գեներացում:** Օգտատիրոջ մուտքագրած գաղտնաբառը անմիջապես չի օգտագործվում։ Այն անցնում է **SHA-256** հեշավորում՝ կայուն և անվտանգ գաղտնագրման բանալի ստանալու համար:
3. **Հիշողության օպտիմիզացում:** Լուծվել է մեծ ֆայլերի (RAM-ի գերբեռնվածության) խնդիրը: Ֆայլերը այլևս չեն կարդացվում ամբողջությամբ հիշողության մեջ, այլ մշակվում են **4 ԿԲ բլոկներով**: Սա թույլ է տալիս անվտանգ գաղտնագրել անգամ գիգաբայթեր կշռող ֆայլեր:

## Հրամաններ և Օգտագործում
Ծրագիրը աշխատում է հրամանային տողից (Command Line)։

* `protectusb scan` - Հայտնաբերել միացված USB կրիչները
* `protectusb list <path>` - Ցուցադրել ֆայլերը նշված պանակում
* `protectusb encrypt <file>` - Գաղտնագրել մեկ կոնկրետ ֆայլ (AES-256)
* `protectusb decrypt <file>` - Վերծանել մեկ կոնկրետ ֆայլ
* `protectusb protect <path>` - Գաղտնագրել նշված պանակի կամ կրիչի բոլոր ֆայլերը

## Տեխնոլոգիաներ
* C++ (C++11 և բարձր)
* Windows API (wincrypt.h, advapi32.lib)
